# ギタレレプロジェクト

ギタレレ（Guitarlele）について調べながら、簡単な内容で楽しくギタレレを弾いていくプロジェクト。
最初は既存曲のカバーで練習しつつ、**最終的にはオリジナルのギタレレソングを作詞・作曲して発表すること**を目指しています。

## 進め方の方針

- 難しい理論や高度なテクニックより、簡単で楽しく続けられることを優先する
- 既存曲のカバーは練習・準備運動の位置づけ
- オリジナル曲の作詞作曲・発表がメインゴール

## ギタレレの基礎知識（要約）

ギタレレはギターと同じ6弦・同じ運指（コードの押さえ方）でありながら、
チューニングがギターの**カポ5相当**になっている楽器。
そのため、ギターの「Cコードの押さえ方」をそのまま弾くと、実際に鳴る音は「F」になる、
というズレが生じます。詳細は [1_ギタレレの基本.md](1_ギタレレの基本.md) を参照してください。

コード表は世の中のほとんどがギター前提のため、フォーム→実音の変換表と
初心者向けの基本コードを [2_コードについて.md](2_コードについて.md) にまとめています。

## user_log.md について

`user_log.md` は、このリポジトリ上でのセッション中にユーザーが発言した内容を、
日時とともにそのまま記録したものです。
Claude Codeのようなツールを使って新しく楽器学習を始める人向けの、
「どんなやり取りで資料が作られていったか」がわかる勉強資料として残しています。
